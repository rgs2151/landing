# Project Sources

Shared titles, authors, links, and website blurbs live in `src/content/site.js`.
The two new blurbs summarize the supplied manuscripts using collective credit.
The Nature blurb and its individual contribution statement are unchanged.

## LLM Steering

- Source PDF: `papers/llm-robust-stimulation.pdf`
- Original attachment: `LLM_Robust_Stimulation__ICLR_2027_ (2).pdf`
- Project website: https://rgs2151.github.io/controller/
- Code: https://github.com/rgs2151/controller
- PDF page 1: title, authors, equal contribution, and abstract.
- The website citation identifies a 2026 unpublished manuscript. The attachment
  filename does not establish ICLR acceptance. Its arXiv button currently links
  to GitHub, so no arXiv publication link is recorded.
- Blurb covers feedback steering, robustness to distribution shifts, unchanged
  weights, and the robust-steerability diagnostic. It does not equate brains
  and language models or claim clinical efficacy.

## NeuralFieldManifold

- Source PDF: `papers/neural-field-manifold.pdf`
- Original attachment: `NeuralFieldManifold.pdf`
- Tutorials and project website: https://erfanzabeh.github.io/NeuralFieldManifold/
- Code: https://github.com/erfanzabeh/NeuralFieldManifold
- PDF page 1: title, authors, abstract, and preprint designation.
- The website's arXiv URL is a placeholder, so no arXiv publication link is recorded.
- Blurb keeps the toroidal-topology claim conditional on the autoregressive
  modeling framework and summarizes the time-varying network and validation.

These PDFs are design references, outside `public/`, and are not served by the
website. Adding them to the project inventory does not alter the current page
or prototype layout. Future media and interaction design can draw on all three
projects rather than treating the LLM sketch as the complete project.
