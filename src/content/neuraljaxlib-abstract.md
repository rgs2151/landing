NeuralJAXlib is a lightweight, GPU-accelerated framework for building and exploring neural networks in JAX, designed for research, experimentation, and education. It provides a unified interface for model construction, training, and evaluation while retaining explicit control over network composition and optimization. Modular components support dense, convolutional, and recurrent networks alongside transformers, autoencoders, and generative adversarial models, allowing architectures to be extended and combined through ordinary Python code. Automatic differentiation and just-in-time compilation support accelerated computation, while customizable training procedures accommodate new objectives and learning strategies. NeuralJAXlib provides a common foundation for understanding established architectures and developing new approaches.
