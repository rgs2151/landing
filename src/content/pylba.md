PyLBA is a Python package for simulating and fitting Linear Ballistic Accumulator models of choice and response time. It brings together synthetic data generation, Bayesian parameter estimation with PyMC, and prediction from fitted models. Parameters can be shared across accumulators or specified separately, with support for fixed values and custom priors. Simulations return pandas DataFrames, and posterior samples integrate with ArviZ for analysis and diagnostics. A consistent interface connects model specification, fitting, and simulation, making it straightforward to explore how evidence accumulation shapes choices and response times.
